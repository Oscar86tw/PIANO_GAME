PIANO LEARNING V5.6
主題：7-SECOND READY BUFFER

新增：
- 按開始後固定 7 秒準備時間
- READY 7.0s → 0.0s 倒數
- 第一顆音符從右側往藍線移動
- Beat 0 才開始出聲
- Beat 0 才開始 Scoring
- Beat 0 才開始節拍器第一拍
- 準備時間內彈琴不算錯

同步方式：
- 不使用另一個獨立倒數 clock
- TransportMaster 從負 beat 開始
- 第一顆音符仍然 startBeat 0
- 五線譜 / 琴聲 / 節拍器 / Scoring 繼續共用 AudioContext Master Clock
