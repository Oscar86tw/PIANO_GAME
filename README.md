# PIANO LEARNING V1.3

## 修正
- 修正 V1.2「譜面鋼琴聲」按鈕沒有 JavaScript 事件，因此無法開關、沒有聲音的問題。

## 真實鋼琴取樣
- 改用 MusyngKite Acoustic Grand Piano SoundFont 真實鋼琴取樣。
- 第一次按「譜面鋼琴聲」會載入鋼琴樣本。
- 載入完成後會先試播 C4，確認聲音正常。
- 五線譜音符到達判定線時，會依譜面音高播放鋼琴取樣。
- 可獨立開 / 關。
- 示範音量可調整。
- 暫停時會停止延音。

## 注意
真實取樣檔從公開 SoundFont CDN 載入，因此第一次使用需要網路，之後瀏覽器通常會快取。
