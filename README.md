# PIANO LEARNING V1.1

## 新增
- 節拍器 BPM 可手動調整 30–240 BPM。
- 每首樂譜開啟時，節拍器預設自動使用該譜 BPM。
- 可按「恢復譜面 BPM」回到原曲速度。
- 練習速度 50% / 75% / 100% 會同步影響實際播放與節拍。

## 對譜紀錄
每次彈奏會逐音記錄：
- 譜面預期音符
- 實際彈奏音符
- 譜面預期時間
- 實際彈奏時間
- 節拍誤差（ms）
- 音高是否正確
- 節拍是否正確
- 是否「音符＋拍子完全吻合」

只有音高與節拍都正確，才算 Exact Match。

練習完成後會把最近練習紀錄保存在瀏覽器 localStorage（最多 100 筆），供後續做進度分析。
