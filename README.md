# PIANO LEARNING V2.1 — Grand Staff

## 新增
- 真正雙譜表畫面：右手高音譜表 𝄞 + 左手低音譜表 𝄢。
- 右手 / 左手 / 雙手模式會直接影響譜面重點顯示。
- 每首內建曲目自動產生左手伴奏型。
- 左手可出現簡單同時雙音 / 和弦視覺。
- 譜面鋼琴示範聲在雙手模式會同步播放左右手。
- READY、播放、暫停、倒回、Master Clock、節拍器與紀錄流程全部保留。

## 目前限制
- 瀏覽器麥克風的基礎 pitch detector 仍以單音辨識為主；真實同時和弦的精準辨識下一階段會改用 MIDI 或 polyphonic pitch detection。
- V2.1 的左手伴奏是教學用自動生成伴奏；匯入 MusicXML / MIDI 的正式左右手 voice/staff 分離會在後續版本深化。
