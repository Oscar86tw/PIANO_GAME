# PIANO LEARNING STUDIO V0.7

Simply Piano 類型的課堂學習介面，新增彩色音符與節拍器。

## V0.7 新增
- C / D / E / F / G / A / B 固定彩色音符
- 五線譜音符、音符跑道同步使用相同顏色
- 音名顏色圖例
- 節拍器 ON / OFF
- 4 拍視覺節拍燈
- 第一拍重拍提示
- 節拍器音量：小 / 中 / 大
- 節拍器 BPM 會跟歌曲 BPM 與 50% / 75% / 100% 練習速度同步
- 暫停時節拍器同步暫停，繼續時重新對拍

仍保留 50 首歌曲、5 級難度、真鋼琴麥克風、五線譜、課程與演奏模式。
