# PIANO LEARNING V1.0

全新重做版本。舊 V0.x 介面不再沿用。

## 核心方向
- 首頁：課程 / 歌曲 / 5 分鐘練習 / 進度
- 練習主畫面：紫色背景、白色五線譜、固定青色判定線
- 五線譜與音符從右往左移動
- 上方進度條與暫停按鈕
- 無大型錯誤文字干擾
- 正確 / 太早 / 太晚只以背景淡色提示
- 節拍不穩時才出現小型節拍輔助
- 支援手機、平板、桌面
- 麥克風真鋼琴單音辨識
- 練習速度、左右手、學習 / 演奏模式

## 下一階段
- 正式 MusicXML / MIDI 樂譜
- 高音 / 低音雙譜表
- 音符時值與休止符
- 小節 Loop
- MIDI Keyboard
