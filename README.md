# PIANO LEARNING STUDIO V0.8 Mobile

V0.8 加入節拍錯誤自動提示，並針對手機與平板做響應式排版。

## 手機 / 平板優化
- 手機直向：五線譜、節拍提示、控制按鈕改為單欄與大觸控區。
- 手機橫向：優先保留五線譜與遊戲區，縮短非必要區域。
- 平板直向 / 橫向：保留完整歌曲選擇與學習資訊。
- 琴鍵縮放、歌曲卡片、難度選單、HUD 自動換行。
- 節拍錯誤時的節拍器提示在小螢幕不遮住五線譜。

## V0.8 節拍輔助
- TOO EARLY / TOO LATE / MISS 時自動顯示節拍器與節拍線。
- 連續 4 個音重新對拍後，自動收起。
