# PIANO LEARNING V1.6 — Ready Mode + Full Curriculum

## 1. 準備模式
點課程或歌曲後「不會自動開始」。
學生可以先設定：
- 主 BPM
- 50% / 75% / 100% 練習速度
- 右手 / 左手 / 雙手
- 演奏 / 學習模式
- 節拍器
- 譜面鋼琴示範聲
- 麥克風

最後由學生自己按 ▶ 播放。

## 2. 固定控制鍵
- ↶ 倒回：回到前一小節（4 拍）
- ▶ 播放
- Ⅱ 暫停
- ● 紀錄：查看本次音高與節拍紀錄

## 3. 完整學習分類
程度：
- 預備級
- Level 1–8

分類：
- 識譜
- 節奏
- 技巧
- 音階・琶音
- 和弦・和聲
- 視奏
- 聽力
- 曲目・演奏

這套分類吸收現代鋼琴課常見技能架構，並參考 ABRSM Practical Grades 的
repertoire / scales & arpeggios / sight-reading / aural 四大核心，以及
Simply Piano 的 Soloist / Chords 路線思路。

## 4. 對譜紀錄
每次實際彈奏仍會記錄：
- 譜面音符
- 實際音符
- 應到拍點
- 實際時間
- ms 誤差
- 音高是否正確
- 節拍是否正確
- 是否完全吻合
